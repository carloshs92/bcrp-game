# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

"Sol Firme" (formerly "Guardián de la Estabilidad") is an educational serious game about BCRP (Banco Central de Reserva del Perú) monetary policy. The player sits on the BCRP board and, in turn-based monthly meetings, sets the policy rate to keep inflation in the 1–3% target band without causing a recession. All player-facing text is in **Spanish**, so keep new strings in Spanish.

The game is plain ES-module JavaScript with DOM, CSS, inline SVG and Web Audio (no framework, no game engine, no asset files), built with Vite. The visual style is institutional with Peruvian touches, such as the Andean textile band and local characters.

## Commands

- `npm run dev`: Vite dev server on port 3000
- `npm run build`: production build to `dist/`
- `npm test`: runs `node --test` over `test/`. To run a single test, use `node --test --test-name-pattern "nivel-1" test/`.

Every push to `main` deploys to GitHub Pages through `.github/workflows/deploy.yml`. `vite.config.js` must keep `base: './'`.

## Architecture

The code is split into layers. Only `views/` and `audio/` touch the DOM or Web Audio.

- `src/model/economy.js` holds a **pure** monthly macro model. `step(prev, newRate, shock, params)` implements the transmission chain the game teaches: policy rate → market rate (partial pass-through, which creates the lag) → real-rate gap vs. neutral → output gap → core inflation. It also adds expectations, anchored by credibility, and decaying supply shocks, and returns `drivers` so the UI can explain *why* inflation moved. `PARAMS` can be overridden per scenario, for example `potentialGrowth`, `credPenalty`, `bigMove`, or `gapToCore`.
- `src/game/mandate.js` is the scenario-driven turn engine used by the tutorial, the history chapters and free mode. One turn is `stepsPerTurn` monthly steps. With `monthlyMeetings`, a move is spread across the quarter's three monthly meetings the way the real BCRP moves. The engine also handles:
  - scripted or random events, plus **surprises** (`SURPRISES`) that are drawn *after* the decision, so the projection never includes them;
  - political `pressure`, where `hikePressure` sets the cost per 25 bp hike;
  - tools such as Reactiva Perú, and a hawk and a dove advisor (invariant: hawk ≥ dove);
  - `projection()` for the live fan chart.
  A seeded PRNG makes runs reproducible. For chapters that define a `realPath`, `evaluate()` scores the player against `Mandate.replayReal(seed)`, which replays the real BCRP rate path under the **same seed**, so copying the BCRP scores exactly 100.
- `src/game/hyper.js` is a separate monthly engine for the 1990 chapter. There the instrument is money emission to finance the Treasury, not the policy rate.
- `src/model/events.js` defines the Peruvian characters (fictional), the random event deck and the surprise deck. `src/model/history.js` defines the tutorial, the 5 chapters, and the interludes. The chapters are 1990 hyperinflation, the 2008 crisis, the 2017 coastal El Niño, the 2020 pandemic and 2021–23 inflation. Each chapter carries real BCRPData rate and inflation series and its sources. The facts in `context`, `reality` and the interludes are real and sourced; keep them that way.
- `src/game/people.js` computes sector moods (−2 to +2) after every turn: low-income families, workers, mypes, debtors and savers (plus state workers in 1990). It also provides the "who wins / who loses" text for each move and the end-of-run human balance. Both engines store the moods in `peopleHistory`. The rule is that every decision has a visible human cost.
- **Regional map.** `src/model/peruMap.js` holds generated SVG paths for the 24 departments; Lima includes Lima Metropolitana and Callao. It is built from Natural Earth admin-1 (public domain) by a one-off projection and simplification script, so don't hand-edit it. `src/model/regions.js` gives each department a qualitative economic profile (channel weights such as `alimentos`, `credito`, `mineria`, `nino`, `heladas`, `central`…), a fictional local character, and the local `product`/`mineral`. It also defines `TAG_EFFECTS`, which map event tags to channels, and `REGION_VOICES`, the phrase banks by cause with `{p}`/`{P}`/`{m}` placeholders. Events, surprises and chapter scripts carry `tags`; `regionMoods()` combines those tags with the national state. The views are `views/peruMap.js` (the colored map with a hover/tap detail panel) and `views/people.js` (the Sectores/Mapa tabs, the newspaper report and the verdict balance, which weighs each region's average and worst turn).
- **Phrases.** Sectors and regions carry a `cause`. `sectorVoice`/`regionVoice` pick a random phrase for that cause and avoid the last 40 used. When you add a cause, add several variants.
- **Congress.** `src/model/congress.js` holds REAL declarations and questions from Peruvian legislators, each with a `source` URL. They are shown **anonymously** in the UI (only year and context), and a test fails if a legislator's name appears in any text. Never add a quote without a verifiable source; trimmed text is marked with […]. The engine's `pressure` doubles as the "Congreso" mood (`congressMood`). It starts at `CONGRESS.start` (50: Congress is always annoyed) and each turn reverts a fraction `CONGRESS.revert` toward that level instead of calming down to zero. When the scenario has `citations: true` (free mode only, so there are no anachronisms in the history chapters) and pressure reaches `CONGRESS.citeAt` or more, `maybeCite()` queues a citation. It fires at most once every `CONGRESS.citeGap` turns and uses a separate PRNG (`crng`) so the shock sequence and calibration don't change. `answerCitation(i)` applies the effects for each style (`tecnica` / `promesa` / `evasiva`). A `promesa` answer sets `congress.promise = 'noSubir'`: hiking the next turn costs credibility and raises pressure, while keeping the promise gives a small bonus. Questions are `kind: 'real'` (verbatim) or `kind: 'recreacion'` (a documented real episode described in `basis`, with the question worded by the game), and the UI labels the two differently. Chapters can set `citationYears` to avoid anachronisms and `scriptedCitations: { turn: questionId }` for episodes that happened at that moment (the 2020 debt freeze, the 2021 dollar hearing). No verifiable pre-2020 questions were found online. **Bills** (`BILLS`, all labeled recreations of real initiatives: AFP withdrawals, rate caps, gold custody, using reserves) come through `maybeBill()`. They start from turn 2, at most one every `CONGRESS.billGap` turns, with a probability that grows with pressure. The player answers with `answerBill(i)`: oppose (archived, unless pressure ≥ `CONGRESS.insistAt`, in which case it passes by insistence), negotiate (half effects) or stay silent (full effects). Effects become temporary shocks in `this.effects`. An unanswered bill counts as "stay silent". All Congress tuning lives in `CONGRESS`. The views show citations and bills before the turn starts (`showCitation` in `play.js`), and declarations appear in the newspaper.
- **FX market** (Phase 2). A scenario with `fx: { rate, reserves }` (free mode, 2008, 2021–23) adds the exchange rate and reserves, and `decide(rate, sell)` takes a second decision, `sell` (US$ bn; positive = sell dollars, see `FX_MOVES`). Each turn: depreciation % = event/surprise `fx` pressure − 1.2 × rate move − 1.0 × sales + noise. The noise comes from its own `fxRng`, drawn once per turn, so the real-BCRP replay sees the same noise. Depreciation feeds inflation through `passThrough` (asymmetric: appreciation passes half), cuts demand (dollarization), and costs credibility when it is above 4%. Reserves below 50% cost credibility, and sales stop at 30%. The chapters' `SCRIPT_FX` pressures are **back-solved** so that replaying the real rate path plus `realPath.fxSales` reproduces the real quarterly exchange rate (`realPath.fxRate`). Recompute them if you change `FX` constants.
- **Communiqué** (Phase A, `GUIDANCE` in `mandate.js`). `decide(rate, sell, tone)` takes a third decision: `halcon` / `neutral` / `paloma`. `guidanceEffect()` shifts expectations at once, scaled by credibility (words are worth nothing without it), plus a small demand/FX/pressure effect; `projection()` takes the same tone. The tone commits the next turn: `breaksGuidance(move)` (hawkish then cut, dovish then hike) costs `GUIDANCE_RULES.broken` credibility and an FX jump, keeping it pays `kept`. Off in the tutorial (`guidance: false`); `replayReal` uses neutral, so the 100-point reference is unchanged. `test/guidance.test.js` pins that always-dovish loses and that tone used with judgment doesn't hurt.
- **Toolbox** (Phase A, `src/game/toolbox.js`, pure). `TOOLBOX` holds the instruments the BCRP created over time (soles/dollar reserve requirements, repos, dedollarization, FX swaps), each with `effect` (`shock`, `fx`, `turns`, `pressure`, `credibility`, `after.fxPass`), a `cooldown` shared by `group`, and a sourced `history` line shown in the newspaper. The 4th argument of `decide(rate, sell, tone, toolId)` applies one per turn; `toolReady()` gates it and `projection()` takes it too. Chapters list their era's tools in `toolbox`; free mode gets `unlockedTools(story.chapters)` and shows the locked ones. These are separate from the scripted chapter `tools` (Reactiva), which `replayReal` uses, so the real-path reference is unchanged. `test/toolbox.test.js` pins that spamming tools doesn't beat using none.
- **Phase B.** (1) `showReaction(rec)` in `play.js`: a live feed between the announcement and the newspaper (the cambista's animated FX rate, an analyst, the two strongest sector voices, Congress). A real legislator quote always goes with the Congress icon, never a character's face, to keep it anonymous. (2) Political-noise events in `EVENTS` (cabinet change, polarized elections, regional strike, vacancy motion): fictional and nameless, with `fx` pressure. (3) `climax: { turn, scene, title, text }` per chapter: a "momento decisivo" turn with its own intro modal and red banner. There the player is compared with `Mandate.replayRealStates(seed)` at that turn (inflation within `CLIMAX.inflationSlack`, growth within `growthSlack`) for ±`CLIMAX.reward/penalty` credibility; in reference mode the replay compares with itself, so copying the BCRP still scores exactly 100. (4) Envy: with inflation in the band and credibility ≥ `CONGRESS.envyCred`, success itself adds Congress anger up to `CONGRESS.envyCap` (60, the citation zone), so it brings citations but never removes you on its own.
- **Phase C.** (1) **Board vote** (`BOARD`, `boardVote()`, free/express only via `scenario.board`). It follows art. 86: 7 members, 4 named by the Executive (incl. the player) and 3 elected by Congress, none representing particular interests. Each director has a preference derived from staff/hawk/dove; a change needs 4 of 7 votes within `BOARD_RULES.tolerance`, and the player may convince one director per turn within `reach`. Without a majority the rate is held, at `lost` credibility; proposing a politically pressured cut with high inflation costs extra. Holding never needs a vote. Chapters don't vote, so historical fidelity holds. (2) **Achievements** (`game/achievements.js`, pure; `views/achievementsView.js` awards and stores them via `storage.unlockAchievements`): Peruvian humor ("Perú es clave", "Chamba es chamba", "A la firme"…), shown in every verdict and in a title-screen gallery. (3) **Mandato exprés**: free mode with `turns: 6`, `yearLength: 2` (event intensity ramps twice as fast), 5 of 6 quarters in band. (4) **Informality** (`INFORMAL`, `scenario.informal = 70.2`, INEI 2025, free/express only): rises when growth is below potential and shows as a card plus the `informal` workers' voice cause. It is narrative and indicator only: it does not change the macro model.
- Difficulty (`storage.js` `DIFFICULTIES`, chosen in Configuración) has three levels. `facil` shows colored hints and "inside/outside target" verdicts. `normal` hides judgment colors through the `.hints-off` CSS class. `dificil` adds a wall-clock decision timer (`createTimer` in `play.js`) that pauses while modals are open; when it expires, nothing changes: the rate is held, and in 1990 the previous choice repeats (or printing money on the first month). The tutorial always runs in `facil`.
- `src/audio/music.js` provides procedural adaptive music with Andean timbres (quena, charango, bombo, cajón). Views call `music.setMood(...)` with `decision`, `announce`, `surprise`, `good`, `bad`, `victory`, `defeat` or `title`. Audio unlocks on the first user gesture.
- **Onboarding.** `views/intro.js` SLIDES is the "¿Qué es el BCR?" intro: 8 one-idea slides, including an interactive inflation calculator (`bindCalc`), the BCR's constitutional functions and what it does NOT do. It is shown automatically the first time the player enters any mode (`withIntro` in `main.js`). The game screens always show a `.mission` bar with the player's role and goal. In `playScenario` each turn is split into four panels (`SECTIONS`: noticias, estado, directorio, anuncio) switched by `goTo()` or keys 1–4; `coach.js` opens the hidden panel that holds a coach mark's target, so tutorial steps can point anywhere. The 1990 chapter (`hyper.js`) uses three panels (noticias, tesoro, anuncio; keys 1–3). Story-mode chapter intros are a slider (`chapterIntro` in `story.js`): the interludes, then the chapter `context`, each with an inline SVG scene from `views/scenes.js` mapped in `SLIDE_SCENES`. Scenes show objects and places, never real people, and must not print figures that aren't in the chapter's sourced text.
- `src/views/` holds the screens. `main.js` routes from the title to one of three modes: the tutorial (`playScenario` + `tutorialScript.js` coach marks), story mode (`story.js` timeline → chapter intro → `playScenario`/`playHyper` → verdict with real-vs-player charts), and free mode. `modal.js` provides the single-modal helper, and `modalOpen()` gates the keyboard shortcuts. `coach.js` queues coach marks so two never overlap. After the last turn, views must not re-render the turn screen, because there is no next event.

## Tuning

Model parameters and scenario shocks are calibrated together. The tests pin the design intent:
- `test/mandate.test.js` covers free-mode balance over 200 seeds.
- `test/history.test.js` checks that each chapter is winnable by replaying the real BCRP path (≥80%), that its real moves fit the chapter's `moves` buttons, and that inaction or the hawk does worse where history says so. It also checks that the 1990 chapter needs the Comité de Caja plus the social program.

When you retune a chapter, print its trajectories under several strategies, such as the real path, the staff Taylor rule, hawk, dove and hold, before touching the tests.
